# FX rates (demo)

`eurofxref.csv` is a **static** snapshot of the ECB euro foreign exchange reference rates.

- Format: `1 EUR = X <currency>`
- Used only to estimate Overview / Analyze totals in EUR when invoices mix currencies
- **Not live.** Do not use for real accounting, tax, or trading decisions

Replace the file with a newer export when you want a fresher demo snapshot.
